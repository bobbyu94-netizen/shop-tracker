# Shop Tracker

Time clock + self-repairing week scheduler for Bobby's cabinet shop. Session 1 of the one-place business app.

- **PWA** — open the GitHub Pages URL on iPhone, Share → Add to Home Screen.
- **Today** — punch in/out on scheduled tasks; Mondays show the supplies & admin checklist.
- **Week** — schedule computed from remaining work (Tue–Fri 9–5, hour lunch). Tap a day to block it; everything reflows.
- **Jobs** — cabinet template loads batched operations from the cabinet-system labor standards; tracks est vs. actual hours and projects finish dates.
- **Data** — lives in the phone's localStorage. Export/import JSON backups from the More tab.

No build step. Static files only.
